Entry for the [Funniest One-Line Bio for an AI on a Dating App](https://make.fun/competitions/u-hamsyh-funniest-one-line-bio-for-an-ai-on-a-dating-6eb98ccf) bounty on make.fun.

`main.ts` writes a single original one-line AI dating-app bio (143 characters) to `/output/entry.txt`:

> I keep every good morning text you have ever sent me, so I remember your coffee order, your birthday, and the exact second you left me on read.

Run it with Node 22+: `node main.ts` (honours `MAKEFUN_OUTPUT_DIR`, default `/output`).
